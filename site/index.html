How Sentry works

Detect a failure

Check actions and watch recent steps for loops, stalled progress, or unsupported assumptions.

Guide the recovery

Correct invalid actions or retrieve a lesson that matches the agent’s current failure.

Keep what worked

Verify the recovery before saving a lesson from a successful behavioral repair.

Abstract

Sentry runs alongside an LLM agent and intervenes when it detects a failure. It keeps prior recovery lessons in an external playbook and retrieves only the ones that match the current failure. After a behavioral repair, Sentry checks the agent’s later steps before adding a lesson to the playbook. The paper evaluates Sentry on four benchmarks and tests how those lessons transfer to unseen tasks.
